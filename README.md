## Research

**Detecting Malicious Packages Using Automated Scanning Tools** (Susan Wheeler Summer Research Program, 2026)

I studied how well automated scanners detect malicious Python packages. Using Datadog's GuardDog, I scanned 110 PyPI packages, 10 of them confirmed malware. GuardDog caught 8 of the 10, including two well-known real-world supply-chain attacks. The two it missed hid their behavior in package metadata rather than code, which shows the limits of static analysis on its own. I also set up OpenSSF Package Analysis to explore dynamic analysis as a complement.

All testing ran in an isolated Ubuntu virtual machine with snapshots, so live malware could be analyzed safely and repeatably.
